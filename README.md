# 🅿️ חניה דגניה 6

אפליקציית web משפחתית לעדכון בזמן אמת: איזה רכב חונה בחניון, האם החניון פנוי, ומי חוסם את מי שבפנים.

**🔗 האתר:** https://bsaviran.github.io/deganya6-parking/

## מה יש באפליקציה
- **איור של החניה** — מקום "בפנים" (לאורך) ומקום "חוסם" (לרוחב), עם הרכב שחונה בכל אחד
- **שלושה מצבים** — ✅ פנוי · 🚗 תפוס · ⛔ חסום, עם צבע שמשתנה בהתאם
- **בחירת רכב** — אקספנג, לקסוס, או "רכב אחר" (אורח) עם שם חופשי
- **מי עדכן ומתי** — "אבירן חנה · לפני 5 דק'"
- **הערה** חופשית ("יוצא ב-8:00") שמופיעה לכולם
- **היסטוריה** — 30 הפעולות האחרונות מוצגות (הכול נשמר ב-Firebase)
- **קוד משפחה** — בלי הקוד הנכון לא ניתן להיכנס
- מותאם לטלפון, מצב כהה/בהיר, ואפשר "להוסיף למסך הבית" כמו אפליקציה

## איך מוסיפים לטלפון
1. פותחים את הקישור למעלה
2. מקלידים את קוד המשפחה ובוחרים מי אתה
3. באייפון: שיתוף ← **הוסף למסך הבית** · באנדרואיד: תפריט ⋮ ← **הוסף למסך הבית**

## שינויים נפוצים
כל ההגדרות נמצאות ב-[`config.js`](config.js):

| מה | איפה |
|---|---|
| להוסיף/לשנות אנשים | `PEOPLE` — `female: true` לניסוח בלשון נקבה ("חנתה", "חסמה") |
| להוסיף/לשנות רכבים | `CARS` — `model: "suv"` או `"sedan"`, `color` לצבע בציור, `photo` לתמונה אמיתית (לא חובה) |

אחרי שינוי — להעלות את `APP_VERSION` ב-`index.html` באחד, ואז `git commit` ו-`git push`. האתר מתעדכן תוך כדקה-שתיים.

## איך זה בנוי
אתר סטטי — HTML, CSS ו-JavaScript בלבד, בלי שרת ובלי כלי בנייה.

- **GitHub Pages** — מארח את האתר (חינם)
- **Firebase Realtime Database** — שומר את המצב ומסנכרן בין הטלפונים בזמן אמת (חינם)

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה הדף |
| `style.css` | עיצוב |
| `app.js` | לוגיקה, ציורי הרכבים וחיבור ל-Firebase |
| `config.js` | אנשים, רכבים והגדרות Firebase |
| `database.rules.example.json` | תבנית לחוקי האבטחה של Firebase |

## הרצה במחשב
```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```
שימו לב: זה מתחבר ל-Firebase האמיתי, אז כל לחיצה משנה את המצב אצל כולם.

## אבטחה
- מפתחות ה-Firebase שב-`config.js` אינם סודיים — הם תמיד גלויים בדפדפן.
- מה שמגן על המידע הם **חוקי ה-Database** ב-Firebase Console: קריאה וכתיבה מותרות רק תחת `homes/<קוד המשפחה>`.
- **קוד המשפחה לא נשמר בגיט** — רק בחוקי Firebase ובטלפונים שלכם.
- להחלפת הקוד: Firebase Console ← Realtime Database ← Rules ← לשנות את הקוד בשני המקומות ← Publish. כל מי שמחובר עם הקוד הישן יוחזר למסך הכניסה.

## הקמה מאפס (אם צריך פרויקט Firebase חדש)
1. https://console.firebase.google.com ← **Create a project**
2. **Databases & Storage ← Realtime Database ← Create database** ← `europe-west1` ← **locked mode**
3. **Rules** ← להדביק את `database.rules.example.json` עם קוד משלכם ← **Publish**
4. **Project Overview ← + Add app ← `</>`** ← להעתיק את `firebaseConfig` ל-`config.js`
5. GitHub ← **Settings ← Pages** ← Branch: `main` / root ← **Save**
